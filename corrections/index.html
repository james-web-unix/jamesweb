Corrections Policy & Change Log

James Web fixes factual mistakes openly. This page explains how to report one and lists dated changes.

Written by AR. Abhinav Ranjan · Last reviewed 3 October 2026

Our policy

We want James Web to be accurate. If you find a factual mistake in a book, a page or its structured data, tell us through the Contact page and include the page address and what you believe is wrong, with a source if you have one.

  1. We check the report against the book and reliable sources.
  2. If it is a mistake, we fix it and note the change in the log below.
  3. If we disagree, we will say why.

Spelling and formatting fixes are not logged individually.
